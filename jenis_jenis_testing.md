# jenis-jenis testing 
pasti ada jenis jenis testing untuk mempermudah kinerja masing masing ,berikut penjelasannya 

1. Regression testing !!!
   testing untuk memastikan perubahan baru tidak merusak fitur-fitur yang telah jalan
   biasanya di lakukan setelah update,fix bug,new feature

2.smoke testing !!!
	testing cepat untuk memastikan seluruh build aplikasi berjalan sebelum melakukan
	testing lebih lanjut 
	biasanya setelah deploy atau build baru  

3.sanity testing!!
	testing singkat pada area spesifik yang telah di perbaiki bug nya 
	biasanya setelah bug fix yang di temukan smoke testing

4.performance testing(bukan tugas qa, jarang )
	test kinerja sistem apakah mampu menjalani kondisi berat 
	

5.system testing (N2N)
	testing keseluruhan aplikasi sesuai spek 
	biasanya ketika sudah deploy atau akan di rilis 

6.unit testing (tugas developer)
	developer test function/ method yang mereka bikin


7.integration testing 
	test komunikasi antar bagian-bagian software yang terhubung ,bagaimana mereka 
	bekerja sama menjadi satu software yang berjalan baik
	biasanya setelah unit testing 
	

8.usability testing 
	testing apakah aplikasi/software layak di gunakan oleh pengguna ,apakah nyaman dari sisi pengguna
