# THECATAPI
**WELCOME TO PROJECT THECATAPI**
this is api testing in website THECATAPI
1.test search image
2.test upload image
3.test delete image
4.test upload breeds at image
5.test get breeds image
and more

if you want to try ,you can follow these steps
1.to get the api key , visit https://thecatapi.com/signup and input your email ,check the email box to get api key (don't share to anyone)
2.create new file .env to configs/ ,paste the api and base link like this 
token= <your api key>
url=https://api.thecatapi.com/v1
3.if you haven't install pytest yet ,you can install in terminal .type pip install pytest, if have done you can in /the_cat_api and type pytest

if you won't
you can open file **test_report.html** with your browser,if not see the table you can follow these steps 
1. type **python -m http.server 8080**
2.open your browser (chrome ,safari,mozilla etc.) and type http://localhost:8080/feat_img.html?sort=result
